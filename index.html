1. ¿Qué son las Animaciones CSS?

Las animaciones en CSS son técnicas que permiten cambiar gradualmente el estilo y aspecto visual de los elementos HTML, pasando de un estado a otro o a través de múltiples fotogramas clave, sin usar JavaScript. Permiten crear movimientos, transiciones complejas y efectos visuales, como cambiar color, tamaño o posición, mejorando significativamente la experiencia del usuario.

2. Ventajas y Usos Principales

Ventajas Clave

  • Rendimiento superior: Procesamiento por GPU.
  • Control creativo: Animación de casi cualquier propiedad.
  • Experiencia UX: Interacciones más naturales y fluidas.
  • Mantenimiento: Código limpio y desacoplado.

Usos Frecuentes

  • Efectos Hover en botones y tarjetas.
  • Transiciones suaves de estados.
  • Micro-interacciones de carga (spinners).
  • Efectos de entrada y salida (Fade/Slide).

Conclusión

Las animaciones en CSS son fundamentales porque transforman una web estática en una experiencia visual atractiva. Al no depender de JavaScript, la web se siente más rápida y fluida.

3. Transiciones en CSS

Una transición es el cambio suave de un estado a otro. Sin ella, los cambios son instantáneos; con ella, el navegador interpola los valores intermedios para una percepción de movimiento fluido.

Los 4 Pilares de la Transición

transition-property
¿Qué propiedad cambia? (ej: opacity).
transition-duration
Duración del cambio (ej: 0.3s).
transition-timing-function
Aceleración (linear, ease, etc.).
transition-delay
Espera inicial.

Ejemplo Práctico Shorthand

.boton {
    background-color: #3498db;
    transition: background-color 0.4s ease;
}

.boton:hover {
    background-color: #2ecc71;
}

Conclusión

Las transiciones son herramientas vitales para el control del flujo visual. Evitan los "golpes" de color y forma, logrando que cada interacción se perciba orgánica y pulida.

4. Transformaciones (Transform)

La propiedad transform no afecta al flujo del documento. El elemento "flota" sobre su propio espacio sin mover a sus vecinos.

Tipos de Transformaciones

  • translate: Desplazar posición.
  • rotate: Girar el elemento.
  • scale: Cambiar tamaño.
  • skew: Inclinar la geometría.

Combinación Maestra

.caja:hover {
    transform: translateY(-10px) scale(1.1);
    transition: transform 0.3s ease;
}

Conclusión

Transform otorga movimiento sin afectar el layout general. Es ideal para botones, tarjetas e iconos, siempre acompañándose de transiciones para un efecto profesional.

5. El Guion: @keyframes

Define los estados de la animación. Puedes usar from e to, o porcentajes para control absoluto. 

@keyframes mi-animacion {
  0%   { transform: scale(1); background: #1f6feb; }
  50%  { transform: scale(1.2); background: #8d6e63; }
  100% { transform: scale(1); background: #1f6feb; }
}

6. El Reproductor: Propiedades de Animation

Asigna el guion a un elemento con parámetros de control:

animation-name
Nombre del @keyframes.
animation-duration
Ciclo completo (ej: 2s).
animation-iteration-count
Repeticiones (ej: infinite).
animation-direction
normal, reverse o alternate.

Ejemplo Aplicado (Shorthand)

.pulsar {
  animation: latir 1s ease-in-out infinite alternate;
}

@keyframes latir {
  from { transform: scale(1); }
  to { transform: scale(1.1); }
}

Conclusión

Las animaciones son más complejas; requieren definir parámetros en @keyframes y luego vincularlos en la propiedad animation para controlar el momento y tipo de ejecución.

7. Resumen de Clase: ¿Cuándo usar qué?

Técnica Cuándo usarla
Transición Cambios simples activados por el usuario (ej: hover).
Transformación Para mover, rotar o escalar la geometría del elemento.
Animación Movimientos complejos que pueden repetirse eternamente.

💡 Tip de experto

Las animaciones consumen más recursos que las transiciones. Úsalas con sabiduría; si llenas tu página de movimientos excesivos, el rendimiento del dispositivo se verá afectado.
